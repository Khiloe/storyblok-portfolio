# Web Editor Practice: Storyblok & Next.js Portfolio

This project was built as a hands-on learning experience to master the workflow of a Web Editor using a Headless CMS (Storyblok) and a modern frontend framework (Next.js).

## What I Practiced
- **CMS Content Management:** Created and managed multiple pages (Home, About, Projects, Contact) using Storyblok.
- **Schema Modification:** Extended default block schemas by adding new fields (Image, Description, and Link fields) to the Teaser and Feature components.
- **Asset Management:** Uploaded and managed images within the Storyblok asset library, ensuring every image includes proper Alt Text for accessibility.
- **Workflows:** Practised the complete draft → preview → publish workflow, managed version history, and applied pre-publish QA checklists.
- **Frontend Integration:** Connected a Next.js App Router frontend to the Storyblok API and styled it using custom CSS, including a dynamic dark mode toggle.

## Tech Stack
- Next.js (React)
- Storyblok (Headless CMS)
- Custom CSS

## Migration Case Study
I performed a practice migration of my old static HTML portfolio into Storyblok. 
- Created a content inventory and redirect map (see `MIGRATION.md`).
- Manually migrated text content from the old site into the new CMS blocks.
- Executed a post-migration QA check on all live URLs and responsive layouts.
