# Pre-Publish QA Checklist

- [x] Spelling and grammar checked.
- [x] Names, dates, and links verified against the source.
- [x] Headings follow a logical order (one H1, then H2, H3).
- [x] No placeholder text left in.
- [x] Every link clicked and working.
- [x] Images load, are the right size, and have meaningful alt text.
- [x] Checked on desktop, tablet, and phone widths.
- [x] Consistent spacing, fonts, and button styles.
- [x] Page title and meta description written and unique.
- [x] Previewed in draft before publishing.
- [x] Checked the live page after publishing.
